🛠 安装插件

支持：GitHub 仓库（owner/repo 或 owner/repo@tag）、 zip 直链（https://…/plugin.zip）、本地目录（local:C:\path）。
安全协议：安装前自动检查兼容性（OS/架构/Electron/DSH 版本）→ 安装后自动运行插件测试 → 测试通过才启用；任何一步失败会自动回滚删除，不会留残留。

🎨 动态壁纸

两种模式： ① 客户端背景（默认）——壁纸显示在 DSH 客户端窗口内（DSH 内容背后/离线时/预览时可见）； ② 系统桌面——挂载到 Windows 桌面图标之下（类似 Wallpaper Engine）。 此功能由内置插件 wallpaper-plugin 提供——若开关是灰的，请先到「推荐」页启用它。

🔌 MCP 服务器（Model Context Protocol）

为 DSH 配置 MCP 服务器，AI 就能调用外部工具（文件系统、数据库、浏览器、网页抓取等）。 配置写入 ~/.dsh/profiles/web/cordis.patch.yml，需要重启 DSH web (3080) 后生效。 工具命名：mcp__服务器名__工具名，GUI 和 QQ 对话都能直接用。

💬 QQ 同步（QQ 机器人双向对话）

在 QQ 里给机器人发消息 → 自动转发给当前 DSH 会话 → AI 回复同步回 QQ。
需要 NapCat（OneBot 11）： ① 安装并登录 NapCat（QQ NT 内核）；② 开启 HTTP 服务器（默认端口 3000）； ③ 开启「HTTP 上报」，上报地址填 http://127.0.0.1:18777/onebot。 详细步骤见 关于页 里的部署说明。
